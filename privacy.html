내 업로더 개인정보처리방침

시행일: 2026년 11월 15일

1. 어떤 정보에 접근하나요

«내 업로더»는 운영자가 Google 계정으로 허락한 범위 안에서 YouTube Data API의 동영상 업로드·관리 권한만 사용합니다. 운영자 본인 채널에 영상을 올리고, 공개 예약 시각을 정하고, 업로드 결과(영상 ID·공개 상태)를 확인하는 데에만 씁니다.

2. 정보는 어디에 저장되나요

Google이 발급한 접근 토큰은 운영자 PC 안에만 저장됩니다. 개발자 서버나 다른 곳으로 보내지 않으며, 이 프로그램에는 별도 서버가 없습니다.

3. 다른 사람과 공유하나요

공유하지 않습니다. Google 사용자 데이터를 판매하거나, 광고에 쓰거나, 제3자에게 넘기지 않습니다. 사람이 그 데이터를 읽는 일도 없습니다.

4. Google API 서비스 사용자 데이터 정책 준수

«내 업로더»가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 접근 권한을 거두려면

Google 계정 → 보안 → 타사 앱 액세스에서 «내 업로더»를 삭제하면 즉시 접근이 끊깁니다. PC에 저장된 토큰 파일을 지우면 남은 기록도 사라집니다.
